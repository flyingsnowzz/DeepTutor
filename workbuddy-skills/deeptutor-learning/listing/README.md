# 上架包内容说明

本目录是 WorkBuddy 审核材料：

- `icon.png`：技能图标（512×512）
- `showcase.png`：展示图（1280×720）
- `short-description.md`：中/英文简介与示例 prompt
- `privacy-policy.md`：隐私政策
- `terms-of-service.md`：用户协议
- `minors-protection.md`：未成年人保护
- `service-dependency.md`：MCP 服务与运行依赖
- `auth-and-unlink.md`：授权、401、解绑说明
- `support-contact.md`：支持与联系（含占位邮箱，需运营替换）

技能本身为声明式文件：`SKILL.md` + `references/` + `templates/` + `examples/`，不含可执行脚本。
