# 授权、401 与解绑说明

## 授权流程
1. 首次使用或返回 401（`UNAUTHENTICATED`）时，技能给出 DeepTutor 托管登录/注册入口。
2. 在浏览器中完成注册或登录（邮箱+密码）；服务签发短期 access token 与长期 refresh token。
3. 宿主保存令牌用于 `Authorization: Bearer ...`；**不要把密码或令牌粘贴到对话中**。

## 令牌与过期
- access token 默认 1 小时；过期由宿主用 refresh token 静默轮换；refresh token 被复用时视为可能泄露，该账户全部 refresh 令牌将被吊销，需要重新登录。
- 若刷新失败，按引导重新登录即可，学习记录仍保留在账户中。

## 解绑与删除
- 在宿主中移除/断开 DeepTutor 连接即解绑；解绑后宿主不再持有有效访问凭据。
- 如需删除账户及学习数据，通过支持邮箱提交申请；删除后不可恢复。
