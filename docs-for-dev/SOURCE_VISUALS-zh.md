# 知识库中的来源可视化

[使用手册](README.md) · [相关指南](INDEXING_RECOVERY.md)

当 PDF 或 EPUB 解析器发出图像文件时，DeepTutor 可以保留提取的源图像。知识库存储经过验证的解析器提取的 PNG、JPEG、GIF 或 WebP 字节，以及确定性资产 ID、文档哈希、解析器身份、源定位器、标题和附近文本。结构化解析器块还保留页面索引和边界框（如果可用）。视觉记录位于知识库的 `visual_assets/` 目录下，与矢量索引分开。访问检查 API 路由 `/api/knowledge-bases/{kb_name}/visual-assets/{asset_id}` 服务于这些确切的字节，删除原始源文件会删除其视觉资产。

LlamaIndex KB 管道为每个源视觉对象的文本记录建立索引，因此文本嵌入模型可以通过其标题和上下文来检索它。当 `rag` 在聊天循环中检索该记录时，具有视觉能力的答案模型会在下一个请求中接收经过验证的图像像素。仅文本模型接收标题和上下文，并明确警告它尚未看到像素。保留所有支持的提取图像，每张图像限制为 5 MiB，并且在一个模型延续中最多发送两个检索到的图像。文档保留计数独立于该模型请求预算。没有文档数字上限或 KB 范围的 16 MiB 清单上限。不可读的清单显式写入失败并保留。

当前的提取覆盖范围取决于所选的解析器。 MinerU 可以生成结构化 PDF 数据。当启用图像提取时，PyMuPDF4LLM 可以生成 PDF 和 EPUB 图像，但其 Markdown 输出不提供页面框。默认纯文本解析器和当前的 Docling 适配器不会发出源图像资源。仅矢量绘图命令的图像或在未配置可用 OCR 引擎时需要 OCR 的页面可能会缺失。其他 RAG 提供商尚未为此视觉清单编制索引以进行语义发现。精确的视觉和 PDF 页面检查独立于嵌入引擎。

## 准确的数字、原始页面和覆盖范围

在知识库的文件视图中，选择一个文档并展开**源视觉覆盖范围**。它显示保留的图形、分页的原始图像链接以及已知的跳过、失败或未经验证的提取位置。不返回图像的解析器永远不会确定文档没有视觉信息。报告描述了提取；它并不证明索引准备就绪或书中的每个视觉效果。

现有的 `rag` 工具还接受 `source_path`、`figure`、`asset_id`、`page`、`region` 和 `source_hash`。使用 `kb_files` 获取准确的文档路径。图和表参考保留其类型和编号；英文/中文标签是等效的。不同来源共享的标签是不明确的，需要选择。对于概念发现，请使用现有的语义检索，并在需要时使用源语言查询。将生成的文档、章节、标题和页面放在一起，而不是将相似的图形视为匹配。

对于矢量图、稀疏标题或依赖于布局的表格，请直接检查 PDF 页面。精确的打印参考发现仅扫描选定的未锁定 PDF，最多 2000 页；多次提及仍然是页面选择。可以独立于该发现限制来选择已知页面。渲染在本地读取原始 PDF，无需 OCR/模型下载或云调用。整页保留布局；标准化 `region=[x0,y0,x1,y1]` 裁剪将有限的像素预算花在更多细节上。一个 PDF 页面上解析器提供的面板组解析为整个页面。结构化表格标题/单元格/单元和注释在提供时仍保留文本证据；原始页面可供验证。

页面检查支持高达 512 MiB 的 PDF，最多具有 800 万个渲染像素和 5 MiB 图像字节。锁定/损坏的 PDF、无效区域和不可读的标签具有明确的限制。其他格式保留支持的提取图像和原始文档访问； PDF 渲染不会默默地应用于它们。增加渲染比例并不能恢复扫描中缺失的信息。

每个解释都包括原始像素和源位置。标题和页面文本与观察到的图像事实不同。重新检索相同的不可变`asset_id`进行详细后续处理；  `source_hash` 保护页面链接。兼容的重新索引使旧资产 ID 保持可用。更改或丢失的来源会被报告，并且旧的参考永远不会重定向到新材料。比较单独的有界调用中的两个源。如果无法检查任一证据，请选择页面/区域，澄清来源，或声明无法进行支持的比较。不需要上传整本书的图像或强制的外部丰富。

综合回归装置包含 100 个源图以及矢量、结构化表格和多面板页面。预期的早期/中期/晚期参考文献、中英图形标签、标题/单位/注释、原始字节、模糊匹配、不可用像素和更改源弃权均独立于语言模型流畅性进行检查。


## 基于来源的实践和学习证据

在引导学习中，明确要求解释、练习或复习。仅用于解释的转向不必提出问题；  `mastery_note_explained` 记录所教授的内容，但不授予掌握程度。推迟目标会使它保持未完成状态。对于需要视觉理解的目标，大纲目标可以声明 `required_visual_tasks`： `identification`、 `relationship`、 `table_graph` 或 `comparison`。通用文本分数无法满足这些视觉要求。客观观点显示了剩余的独立证据。

请求在附加知识库中的精确原始图形或页面上进行练习。导师检索其像素，然后使用 `visual` 上下文构成 `mastery_quiz`。问题卡显示原始证据和文档/页面链接。支持编号标签识别、来源支持的关系问题、表格或图形解释以及有界的两个来源比较。不使用自动分割、发明的标签蒙版或生成的替换图。无法加载的源图像会禁用提交，但仍允许学习者跳过或寻求帮助。

参考码使用规范的源术语和支持标题、解释或页面引用。经过明确验证的等效术语（包括其他语言）可以回答相同的问题。选择题区分支持的错误答案；未知的自由文本措辞需要澄清，而不是模糊的关键词分级。不确定/冲突的键、无法访问或更改的源以及丢失的模型输入像素保持未分级，并且不会产生负面的掌握或保留证据。图形 URL 或声明的视觉功能是不够的：主动循环检查接受的提供程序请求中的匹配图像字节，包括实际的纯文本回退。

可见/未知的答案线索是指导性练习，保留了帮助，并提供了较弱的审查证据。他们没有表现出独立的掌握。提供参考答案的整页保持引导；当答案提示位于视图之外时，经过验证的原始页面区域可以支持独立解释，并保留完整的源以供参考验证。最近的帮助、重复的答案关键暴露以及问题后提供的帮助也可以通过现有的保留会话边界进行区分。

使用**审查或质疑此评估**来请求来源审查。现有的 `mastery_repair_question` 会使错误的评估无效，并重新计算其掌握/错误/复习效果。纠正视觉键也需要源支持；仅靠挑战永远无法带来精通。手动学习器覆盖保留其单独的来源。来源/人物身份、目标、任务、提示/帮助、答案和尝试身份在重新启动后仍然有效。传输重试记录一次尝试；新问题记录新证据。大纲替换保留了可信的客观身份，而不是通过头衔或职位转移成就。未经评估、解释、协助和独立展示的工作仍然是不同的。

回归工作流程使用独立指定的合成编号数字、关系和表值，包括等效语言答案、错误选择、未分级歧义、修复、推迟、重复提交、大纲替换、源更改和重新启动。该支持集提供了对不确定性的明确恢复，而不是承诺对每个图像或任意散文答案进行无限制的评分。

## 图像请求的令牌估计

当提供者返回使用情况时，DeepTutor 使用这些报告的计数器。当不存在使用情况时，会话统计数据将被标记为估计值。回退以每个标记大约 3.5 个字符对序列化文本进行计数，并为每个结构化图像块添加 1,024 个标记。它从文本估计中排除图像 URL 和 Base64 有效负载，因此编码文件大小不会将计数器增加到数百万个令牌。

图像余量是一个粗略的占位符，与分辨率、细节、型号和提供商无关；这不是计费计算。每个模型调用仍然会计算自己的输入，包括任何重播的图像。此更改不会重写现有存储的估计，并且保留对话内容。

## 恢复MinerU云PDF切片

使用文档解析设置中的 `engines.mineru.max_pages_per_part` 对大型云 PDF 进行切片（默认 180；限制为 1–200）。保存旧版 MinerU 设置表单时，会保留此高级设置。本地解析和小/非 PDF 输入保留其现有行为。

合并的内容列表 `page_idx` 值引用原始 PDF，包括嵌套块。例如，第二个 180 页切片的页索引 0 变为 180。无效的本地索引使解析失败，而不是默默地错误标记源页。其他每个部件的诊断工件保留其原始本地编号和 `partNN_` 文件名前缀。

完成的切片存档保存在 `.mineru-segments/` 中活动工作区的解析缓存下，位于一次性失败解析目录之外。重试相同的源和解析器设置会重用已完成的切片；更改的文档、端点、模型、语言、OCR/公式/表设置或切片大小会启动新的检查点集。 API 令牌和签名 URL 永远不会写入检查点。每个存档在重用之前均经过 SHA-256 检查；再次下载不完整或损坏的检查点。并发作业仍可能重复云请求，但检查点写入是原子的。缓存写入失败不会导致解析失败。

这些档案包含已解析的文档内容、图像以及 MinerU 返回的任何源副本，就像普通的解析缓存一样。它们将被保留，直到工作区缓存被清除为止；在没有解析运行时删除 `.mineru-segments/` 只会丢弃可恢复的进度。此更改版本云解析器签名，因此旧的合并页面索引不会从正常解析缓存中重用。现有的知识库索引需要显式重建才能使用更正的页面。

## 重试本地 MinerU 文档

本地MinerU重试从头开始重新启动中断的文档； CLI 不会在推理调用中公开可靠的检查点。兼容的已完成文档解析在重试​​或重新启动后仍然可重用，包括仅在嵌入配置发生更改时。空或不可读的缓存输出将被重新解析，而不是被视为完整。

新的本地输出在替换现有解析之前会检查可用的降价或内容块。失败的尝试保留其工件用于诊断。在工作区解析缓存中，这些文件被移动到受影响签名旁边的隐藏 `.failed-` 目录中，位于下一次重试的工作目录之外。它们永远不会被视为已完成的缓存条目。清除工作区解析缓存也会删除这些诊断工件。在调用者开始另一次尝试之前，中断的本地子进程会停止。

## 使用 MinerU 扫描微小的 PDF 页面

一些扫描的 PDF 将全分辨率页面编码在异常小的物理页面框中。 MinerU 的官方云后端可以选择在临时上传副本中放大这些页面。保留原始文件、页顺序、压缩图像字节和软掩码；语言、OCR、模型、公式和表格设置保持配置不变。这是一种几何解决方法，不能保证更好的 OCR 或保留任意交互式 PDF 语义。

该选项默认为关闭。管理员可以通过现有的 `PUT /api/settings/document-parsing` 端点使用以下部分负载启用它：

```json
{"engines": {"mineru": {"normalize_tiny_scans": true}}}
```

使用 `false` 禁用它。该选项还存在于 `document_parsing.json` 中的 `engines.mineru.normalize_tiny_scans` 中。启用它会更改云解析缓存签名；旧的解析保持不变。现有索引不会自动重建。可选的 `deeptutor[parse-pymupdf4llm]` 轮额外提供所需的 PyMuPDF 依赖项。要检查源，请使用 `python scripts/install_extras.py parse-pymupdf4llm`（请参阅[模块安装](MODULES.md#source-checkout)）。

只有最长边低于 144 点且高分辨率图像覆盖页面至少 80%、表观密度至少为 1200 DPI 的无文本页面才符合资格。最长边缩放为 768 点。旋转、裁剪、注释、矢量轴承或非默认 UserUnit 页面保持不变。本地 MinerU、自定义云端点、普通 PDF 和非 PDF 输入保留其现有行为。成功或失败后，临时副本将被删除，如果压缩图像流发生变化，上传将被拒绝。

## 可选的图像描述批次

现有的 LlamaIndex 图像描述传递可以为每个视觉请求发送多个图像。设置 `image_description_batch_size` 到 `PUT /api/knowledge-bases/rag-pipelines/llamaindex/config`，例如：

```json
{"image_description_batch_size": 4}
```

默认为 `1`，保留单个请求；可接受的值被限制为 1-8。启用并发限制计数批次，现有超时涵盖整个批次，包括任何拆分尝试。返回的标题通过显式 ID 进行匹配，而不是通过响应顺序进行匹配。格式错误的 JSON/ID 映射和显式上下文溢出分成较小的组，最终使用现有的单图像提示。一组 N 个图像最多进行 2N−1 次完成调用，并且在此模式下禁用提供者重试。身份验证和速率限制会停止作业中的排队组；其他 API/传输错误不会拆分。

这仅影响现有 LlamaIndex 描述通道中后续处理的图像。它不支持对结构化来源可视化的描述或更改阅读材料标题。批次使用不同的结构化提示并缓存完整、成功的组，与独立的单图像标题分开。摘要包括有序图像内容和元数据、提示、模型标识和重试策略。失败、不完整或取消的组不会被缓存；成功的分割组可以重复使用。将大小设置回 `1` 可恢复正常的单图像路径。模型必须支持多个图像块；报告不受支持的 API 响应，而不会爆发回退请求。
