# DeepTutor × WorkBuddy 能力测试优先级

日期：2026-11-03

## 验收原则

1. 必须实际调用 DeepTutor，不能用 WorkBuddy 宿主生成内容冒充集成成功。
2. 不只检查 `succeeded`，还要检查本领域产物是否完整、正确、与主题一致。
3. 占位、空输出、研究大纲、脚本文本、宿主替代产物均不能算能力验收通过。
4. 超时、缺依赖或模型失败必须明确呈现，不能静默降级成另一个成功故事。

## 第一优先级：目前未通过的能力

| 顺序 | 能力 | 集成检查点 | 通过标准 |
| --- | --- | --- | --- |
| P0-1 | 深度研究 `deep_research` | 大纲确认后是否继续执行研究与报告 | 完整研究报告，含分主题内容、证据与引用，不能只有大纲 |
| P0-2 | 音频导学 `audio_overview` | 知识库检索、脚本、TTS 与产物收集 | 可播放 MP3 + 逐字稿，不能只有脚本 |
| P0-3 | 视频课 `video_lesson` | 代码生成、Remotion 校验、HTML 产物 | 可打开的 HTML 视频课，画面、字幕和旁白正常 |
| P0-4 | 数学动画 `math_animator` | 代码生成、Manim 渲染与 MP4 收集 | 符合主题的 MP4，不能只有代码或重试记录 |

## 第二优先级：MCP 已通过，需 WorkBuddy 实测

- 分步解题：DeepTutor 返回完整求解步骤，而不是宿主讲解。
- 主观题判分：错误答案得到具体错因和形成性反馈。
- 资料精读：基于 PDF 回答并带页码/章节引用。
- 掌握路径：生成后可通过 `mastery_map_get` 读取阶段目标。
- 练习闭环：出题 → 入库 → 作答 → 判分 → 错题 → SRS 复习。
- 产物下载：`artifact_get` 短期链接能下载正确文件。

## 第三优先级：上线稳定性

- 长任务取消、超时和失败提示；
- `ask_user` 追问与继续执行；
- 幂等、额度与防重复扣费；
- HTTP 多账户隔离与 401 登录引导；
- 弱网或模型失败时禁止宿主静默代做。
