# 语音配置和适配器开发

[使用手册](README.md) · [智能体设置](AGENT_SETUP.md) · [视频学习](watching-workspace.md)

TTS（语音合成）和 STT（语音识别）在语音设置中拥有自己的提供商配置文件和默认值，与聊天模型无关。

## 配置并验证

1. 选择已实施的提供程序并提供其端点、确切的模型/资源 ID 和凭证类型。
2. 在支持的情况下通过提供商发现声音。语音 ID 不是永久的捆绑目录；帐户特定的声音和模型 ID 仍然可编辑。列出的声音并不能证明帐户的权利。
3. 选择该型号系列支持的语言、格式和其他选项。
4. 预览一个简短的示例，然后保存/选择默认值。预览使用当前表单而不更改保存的默认值。
5. 保存后验证实际朗读或转录。仅模型列表的成功并不能证明语音合成或识别有效。

预览会调用提供程序并可能导致使用。表单更改使旧预览失效；可以取消飞行中预览。请求超时接受 5–600 秒，默认为 60。短示例有助于隔离配置错误。

## 提供商边界

- **Volcengine 语音：** 语音凭证与 Ark LLM 密钥不同。该适配器接受语音 API 密钥身份验证和较旧的应用程序 ID/访问令牌形式。匹配 TTS 资源和语音系列。 STT 使用录音文件 API；音频标准化可能需要系统 FFmpeg。
- **Aliyun DashScope：** Qwen3 TTS 和 Qwen-Audio TTS 具有不同的原生端点和参数。适配器标准化支持的官方兼容模式基础；专用端点必须实现所选协议。匹配关键点和端点区域。通过发现和实际预览来确认声音，而不是假设旧示例仍然可用。
- **其他适配器：** 兼容的聊天端点不建立兼容的语音 API。模型选项和实时发现决定了支持的语音和格式。

保留不同的身份验证、区域/模型、权限、速率限制、超时和音频下载错误，而不会暴露凭证响应。保留取消和配置的超时，而不是添加无限制的重试。
