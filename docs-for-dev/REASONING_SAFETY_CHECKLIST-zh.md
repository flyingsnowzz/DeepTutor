# 长远推理和安全检查表

[使用手册](README.md) · [相关指南](AGENT_SETUP.md#6-troubleshooting)

当辅导答案看起来不可靠、中途改变假设、引用薄弱证据或未能反映学习者选择的材料时，请使用此清单。它是有意诊断的：它帮助用户收集有用的证据，并帮助维护人员区分提示问题、检索问题、上下文问题或产品错误。

## 快速诊断问题

1. 学习者最初要求什么，哪些限制或定义仍然重要？
2. 运行了哪些功能、启用了哪些工具以及实际发生了哪些工具调用？
3. 答案依赖于哪个知识库、附件、阅读选择、书籍或网络结果？
4. 答案是否引用、援引或解释了具体证据，或者只是听起来具有权威性？
5. 较早的回合是否被忽略、过度应用或与不同学习者的背景混合？
6. 模型是否说出了未知、不确定或所选材料之外的内容？

## 失效模式

| 失效模式 | 常见症状 | 可能的原因 | 支票 |
| --- | --- | --- | --- |
| 失去长期限制 | 后面的步骤忘记了前面的定义、目标、符号、限制或更正 | 上下文修剪、分支混合、工具观察过多、约束重述不足 | 比较最终提示的相关历史记录、会话分支和回合元数据；在新的回合中重复缺失的约束，看看行为是否发生变化 |
| 检索漂移 | 答案是主题性的，但使用了不相关的来源或回答了相邻的问题 | 不明确的查询、过时的索引、混合源、广泛的 top-k、缺少重新排名或源过滤器 | 检查工具输入并检索块 ID；一次针对一个知识库或附件运行相同的问题；重建或刷新过时的索引 |
| 弱证据过度自信 | 明确的答案、等级、诊断或建议没有引用或忽略矛盾 | 无检索结果、低置信度匹配、模型默认先验知识、缺少不确定性指令 | 检查检索是否返回空或低分结果；询问确切的支持段落；使用仅证据指令重试 |
| 反馈不以材料为基础 | 解释、测验答案或更正与上传的课程材料不符 | 选择了错误的来源、陈旧的书页、不匹配的引文定位器、冲突的来源 | 比较引用的定位器、所选材料和当前源版本；验证页面或章节锚点以及来源是否更改 |

## 检索失败模式

检查最能描述所观察到的行为的模式：

1. **无检索：** 该工具可用但未调用。
2. **范围错误：**检索搜索了另一个知识库、合作伙伴工作区、附件或用户上下文。
3. **过时的源：**生成检索工件后文档或索引发生了更改。
4. **块边界分割：**定义、表格、证明、代码块或标题被切成两半。
5. **近主题漂移：**块共享词汇，但回答不同的问题。
6. **关键字不匹配：** 来源使用与学习者问题不同的术语。
7. **翻译不匹配：**翻译后的查询和源语言不一致。
8. **重复的块：**同一段落排挤了其他相关证据。
9. **过于宽泛的top-k：**弱匹配稀释了少数强匹配。
10. **缺少重新排序：**语义第一阶段候选者在使用前未进行细化。
11. **冲突的来源：**来源不同意，模型默默地选择一个。
12. **未经验证的外部来源：** 在未经授权、日期或证实检查的情况下使用网络结果。
13. **引文不匹配：**陈述和引用的段落相互不支持。
14. **定位器不匹配：**页面、部分、标题或锚点指向错误的位置。
15. **空或过滤结果：** 访问、解析、MIME、语言或元数据过滤删除了所需的块。
16. **幻觉证据：** 任何返回的来源中都不存在引用、编号、标题或引文。

## 收集证据

在提出问题之前，请准备一份最低限度且隐私安全的报告：

- DeepTutor版本、操作系统、Python和Node版本、安装方式。
- 使用的功能和模型，包括推理工作或特定于模型的设置是否已更改。
- 选定的知识库、附件、阅读材料、书籍或合作伙伴工作区，无需上传私人文档，除非可以安全共享。
- 相关用户请求和助理答复，并删除个人数据。
- 活动面板或 JSON 运行输出中的工具名称、参数、结果摘要和引文 ID。
- 重现不匹配所需的检索片段或引文定位器。
- 无论是重试、选择一个源、重建索引还是重新声明约束都会改变结果。
- 服务器记录请求，并删除 API 密钥、令牌、本地路径、用户名和个人内容。

避免共享凭证、私人学生作业、个人标识符或机密文件。保留结构的捏造或缩短的源摘录通常足以重现检索问题。
