# 长文档索引和恢复

[使用手册](README.md) · [相关指南](EVENTS_AND_PROGRESS.md)

每个知识库在 `.indexing-run.json` 中记录其最新的索引运行。文件/详细信息视图显示**索引恢复详细信息**，包括单个源结果、当前阶段和阶段本地计数、运行时间、自输出/活动以来的时间以及自可测量进度以来的时间。到达最后一批的阶段并不能证明整个索引已准备就绪。未知的工作中断后依然未知；它永远不会被视为一份成功的文件。

`GET /api/knowledge-bases/{id}/indexing-readiness` 执行轻量级解析器、格式和嵌入配置检查，无需下载模型或发送提供程序请求。就绪性并不保证以后的下载、可用的 RAM 或 GPU 内存，也不保证提供商的运行时响应。运行时故障在持久运行中保留其有限的、经过凭据编辑的原因。

重试使用现有的内容寻址解析器缓存：源字节和解析器签名必须匹配，并且可用文本或块必须仍然存在。 MinerU 云 PDF 切片仅重用经过验证的检查点。更改嵌入可以重用解析，但会为新的嵌入签名构建单独的索引版本。中断的阶段没有可用的检查点重新启动；日志本身不是第二个缓存，并且不会制造部分嵌入。

取消是特定于任务的，并在安全边界内生效。托管的本地 MinerU 进程也会观察到取消，并在 600 秒无输出或总计 7200 秒后失败。其他同步引擎不能任意中断；在他们返回之前，取消仍处于等待状态。停滞的 LlamaIndex 执行器在实际退出之前被禁止重叠同一进程重试，并且在失去所有权后无法发布其候选者。

LlamaIndex 重建和增量添加使用新版本目录。候选者保持未发布状态，直到其持久索引重新加载、其向量验证并且使用存储向量的检索探针返回节点。发布元数据以原子方式写入。索引期间的源更改会拒绝发布。失败或部分候选不会覆盖以前的可查询版本。已完成和失败的源分别报告，包括部分成功。持久日志的范围是活跃用户/工作空间知识库；链接/只读知识库无法通过突变途径取消。
