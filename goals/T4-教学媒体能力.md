# T4 — 教学媒体能力

> Codex goal-mode target：完成本目标时，必须交付“产出物”中的文件/代码，并按“验收命令”运行测试，留下可审查证据。


## 目标

在云端多账户服务稳定后，补齐 DeepTutor 作为全学段 AI 学习平台的核心教学能力，供自有 App/Web 与 WorkBuddy 等外部宿主通过 MCP 使用。Skill 包创建与上架由 T5 负责。

## 前置依赖

- T3 云端多账户 streamable HTTP 服务可试用。
- 账户隔离、额度、artifact、审计已通过验收。

## 范围

### 1. 沉浸式精读实时会话

开放：

- `reading_session_start`
- `reading_session_reply`

能力映射：`immersive_reading`。

要求：

- 支持教材、PDF、论文、课件和视频材料；
- 返回页码、章节或时间戳引用；
- 支持逐段总结、提问和复习题；
- 实时会话与一次性 Job 明确区分，不把精读伪装成普通长任务。

### 2. 视频课

开放：

- `lesson_video_generate_submit/get`

能力映射：`video_lesson`，依赖 Node.js/npm/Remotion/TTS。

要求：

- `capabilities_list` 显示依赖是否就绪；
- 渲染任务可取消；
- 产物写对象存储；
- 返回短期授权 URL；
- 提交前提示耗时和成本。

### 3. 数学动画

开放：

- `math_animation_generate_submit/get`

能力映射：`math_animator`，依赖 Manim、LaTeX、ffmpeg。

要求：

- 缺依赖时明确返回 missing dependency；
- 代码生成、重试、渲染都在服务端受控运行；
- 不暴露 shell 或服务器路径。

### 4. Hook 与复习触发

实测并实现 WorkBuddy/外部宿主可用的 Hook 触发模型：

- 触发时机；
- 入参；
- 幂等键；
- 失败重试；
- “任务结束后生成复习任务”的事件流。

如果宿主 Hook 不可用，则提供 DeepTutor 侧轮询/定时复习方案，不在 Skill 中伪造 Hook 能力。

### 5. 教学媒体工坊 Skill 消费契约

T4 只提供后端工具和媒体作业能力；Skill 的创建、目录、frontmatter、本地调试和上架流程由 [T5-WorkBuddy技能包开发与上架](./T5-WorkBuddy技能包开发与上架.md) 负责。

本目标需提供给 T5：

- 精读会话工具契约；
- 视频/Manim 动画工具契约；
- Hook 事件契约与重试规则；
- ready/missing dependency 返回；
- 媒体成本/耗时提示；
- artifact 授权 URL 获取方式。

### 6. 可观测与运营

- 按能力统计成功率、耗时、失败原因；
- 模型/TTS/渲染成本；
- artifact 存储成本；
- 媒体任务取消率和重试率；
- 宿主来源渠道标记。

## 产出物

- 精读会话、视频课、数学动画、Hook 和媒体作业 MCP 工具
- 依赖就绪检测
- WorkBuddy Skill 包
- 上架说明与审核材料
- 媒体任务监控面板或报表
- 端到端演示账号与演示脚本

## 完成标准

- [x] 学生可完成一次“资料精读 → 引用页码/章节 → 复习题”（章节引用三学段 E2E + PDF 页码引用服务测试 + 字幕时间戳 HTTP 测试）。
- [x] 视频课或数学动画至少一种可从提交走到 artifact URL（`video_lesson` Job→succeeded→900 秒授权 URL；真实 Runner 会收集渲染 mp4）。
- [x] Manim/Remotion/TTS 依赖缺失时 `capabilities_list` 明确提示不可用（本机 manim 缺失实测：missing_dependency + submit 返回 503 `CAPABILITY_UNAVAILABLE`）。
- [x] Hook 重复投递不会重复创建复习任务（`hook_deliveries.idempotency_key` 唯一 + 来源唯一约束；测试覆盖首次/重放只建 1 个任务）。
- [x] 长任务不会阻塞 MCP 调用（全部走异步 Job Service，submit 立即返回，媒体 notice 告知耗时）。
- [ ] Skill 通过 WorkBuddy 静态规范和安全扫描 —— **移交 T5**：T4 只交付消费契约（`docs-for-dev/mcp/media-tools-contracts.md`），Skill 包创建/扫描/上架在 T5。
- [x] 文案不承诺提分、官方成绩或认证（判分明确“形成性反馈”；媒体 notice 只说明耗时/成本）。
- [x] 所有产物按账户授权访问（媒体 Job/artifact 跨账户 NOT_FOUND，继承 T3 owner 隔离与对象存储短期 URL）。
- [x] 成本、耗时和失败率可追踪（`source_channel` 渠道标记 + `/v1/ops/capability_stats`：成功率、平均耗时、取消、token/成本、artifact 存储量）。

## Codex 实施任务

1. 在 `deeptutor/mcp_server/tools/` 中新增 reading、video、math_animation 和 hook/review 工具。
2. 每个工具只做参数适配和权限/结果裁剪，复用现有 `immersive_reading`、`video_lesson`、`math_animator` 和复习调度能力。
3. 所有长任务通过通用 Job Service 执行，产物写对象存储。
4. 在 `capabilities_list` 中暴露模块 ready/missing dependency 状态。
5. 为 K12/大学/研究生三类典型学习话术建立端到端测试。
6. 对 Manim/Remotion/TTS 缺失、超时、取消、失败提供可解释错误。
